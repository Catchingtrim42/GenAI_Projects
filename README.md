# GenAI Projects 🚀

A curated collection of Generative AI applications, Retrieval-Augmented Generation (RAG) architectures, and machine learning experiments. This repository showcases hands-on implementations exploring natural language processing, computer vision pipelines, and interactive AI web interfaces.

## 🛠️ Tech Stack & Frameworks

* **Languages:** Python
* **LLMs & Frameworks:** LangChain, Hugging Face Transformers (`transformers`, `datasets`)
* **Computer Vision:** PyTorch, YOLOS (`YolosImageProcessor`)
* **Model Deployment & Web UIs:** Gradio, Streamlit, FastAPI, Flask

## 📂 Project Highlights

* **Neural Translation Interface:** Custom Gradio web applications powered by multilingual sequence-to-sequence models (such as `facebook/nllb-200-distilled-600M`) for cross-lingual text translation.
* **Object Detection Pipelines:** PyTorch-based implementations utilizing vision models like YOLOS for real-time bounding box extraction and logit processing.
* **RAG & Conversational Agents:** Intelligent context-retrieval scripts and multi-turn conversational pipelines.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Catchingtrim42/GenAI_Projects.git](https://github.com/Catchingtrim42/GenAI_Projects.git)
   cd GenAI_Projects

```

2. **Install dependencies:**
```bash
pip install -r requirements.txt

```


3. **Run a project module:**
Navigate into any specific project directory and launch its respective script or interface (e.g., Streamlit or Gradio app).
